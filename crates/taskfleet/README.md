# taskfleet

Canonical Taskfleet command-line package. It contains the sole CLI parser,
dispatcher, and execution engine and installs only the `taskfleet` binary.

The package and crates.io saga are release-ready, but ADR 0002 R7 still blocks
the 0.6.0 cut while cargo-dist and Homebrew topology are prepared. The workspace
version and repository URL remain at their truthful pre-transition values.
