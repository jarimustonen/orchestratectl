# taskfleet-core

Canonical state, locking, projection, and supervisor-protocol library for
Taskfleet. The package does not provide a binary.

The crate and R7 distribution topology are prepared, but the 0.6.0 cut remains
blocked through ADR 0002 R8-R10. The workspace version and repository URL
therefore remain at their truthful pre-transition values.
