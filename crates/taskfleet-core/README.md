# taskfleet-core

Canonical state, locking, projection, and supervisor-protocol library for
Taskfleet. The package does not provide a binary.

This source tree is in the pre-cut phase of ADR 0002: the workspace version and
repository URL intentionally remain at their current values until the gated 0.6.0
release work owns the version bump and public repository transition.
