# taskfleet-core

Canonical state, locking, projection, and supervisor-protocol library for
Taskfleet. The package does not provide a binary.

The crate is release-ready, but ADR 0002 R7 still blocks the 0.6.0 cut while
cargo-dist and Homebrew topology are prepared. The workspace version and
repository URL therefore remain at their truthful pre-transition values.
