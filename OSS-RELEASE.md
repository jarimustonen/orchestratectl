## Release notes
- **crates.io publishes are permanent.** Publishing `octl-core@<v>` and `orchestratectl@<v>`
  cannot be undone — a version can be yanked but never re-used or overwritten. Verify both
  crates' `version`/dependency pins before the first publish.
- **Dependency-ordered publish.** `octl-core` must be published before `orchestratectl` (the CLI
  depends on the library); cargo-dist / the release engine handles ordering, but a manual
  fallback must respect it.
- **cargo-dist owns `release.yml`.** It is dist-autogenerated — regenerate it via
  `dist init` / `dist generate` after changing the dist config, don't hand-edit, or the next
  `dist` run will clobber your edits.
- **A pushed Go-style/prerelease tag is cached** — GitHub Releases and any downstream installer
  URLs are tied to the tag; deleting a published release leaves dangling installer links.
